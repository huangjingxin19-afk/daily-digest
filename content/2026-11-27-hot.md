**AI 热点 · 11月27日**

**新模型**

**1. Sakana AI 发布 Namazu Small：30B 推理模型，25 项评测均分超过英伟达 120B 的 Nemotron 3 Super，11月25日**
在 NVIDIA 开源的 Nemotron 3 Nano 底座上继续预训练和后训练而成，总参数 30B、每 token 只激活 3B，主打联网调研和长文档问答；官方自报 25 项评测均分 60.1，高于 120B 的 Nemotron 3 Super（56.2），其中 BrowseComp 网络调研题 73.5 分，约两倍于 Super 的 36.1。但纯凭记忆的知识问答明显偏弱，SimpleQA 只有 6.8 分，远低于 Super 的 18.1。目前没有公开权重和 API，企业本地部署方案要到 12 月才公布细节；跑分均为官方自报。 [MarkTechPost（转述 Sakana 官方发布）](https://www.marktechpost.com/2026/11/26/sakana-ai-namazu-small-30b-nemotron-3-nano/)

**2. 字节跳动 Seed-TTS 3.0 上线：100+ 种语言语音合成，文本里直接写表演指令，11月25日**
字节 Seed 的流式文本转语音模型，支持 100 多种语言及变体，亮点是 82 个行内音频标签：31 种情绪、23 种语气提示、28 种非语言声音（如耳语、笑声），把 [whispering] 这类指令直接写进文本就能控制表演；另有语速、音调、音量控制和可选音色。fal 上按 $0.02/千字符计费，BytePlus 按 $20/百万字符计费，约为 Eleven v4（$80/百万字符）的四分之一；闭源模型，只能走 API 或 Dreamina 音频工作台调用。 [The 9（转述 ByteDance Seed 上线信息）](https://news.the9.pro/models/seed-tts-3-0/)

**3. 印度发布首个本土主权基础模型 Chariot-1：11B MoE，覆盖英语和 10 种印度语言，11月26日**
印度 IndiaAI Mission 资助的首批四个本土基础模型团队之一 Chariot AI 在新德里发布，语言模型与语音模型均在印度从零预训练。Chariot-1 LLM 是 11B 混合专家模型，每 token 激活 4B 参数，一次训练同时产出 10.7B、1.7B、745M 三档尺寸，分别对应数据中心、笔记本和手机；TTS 覆盖英语和印地语、孟加拉语、泰米尔语等 10 种印度语言。性能数据目前只有官方说法，尚无独立评测。 [印度政府新闻局（PIB）官方通稿](https://www.pib.gov.in/PressReleasePage.aspx?PRID=2341725&reg=48&lang=2)

**新应用与新功能**

**4. Perplexity 推出 Time Machine：让搜索 API 查“过去的互联网”，给智能体评测去后视偏见，11月25日**
Search API 和 Context API 新增 `snapshot_as_of` 参数，可指定过去 365 天内任意时间点，只返回该时刻之前保存的网页快照，排名也按旧文本打分，Context API 的全文读取不再实时抓取；用来评测预测、训练智能体时，避免模型从“已经知道结局”的实时网页上偷看到答案。按原价计费，不加钱：Search 每次请求 $5/千次，Context 每千个 URL $1；已向现有 API 用户开放。 [Perplexity 官方更新日志](https://docs.perplexity.ai/docs/resources/changelog#november-2026)

**5. Cloudflare 推出 Search for Agents：一个开关就给网站加上智能体可发现的搜索接口，11月25日**
在域名后台点一下开关，Cloudflare 就会为该域名自动创建 AI Search 实例、抓取并索引站内内容，并在自家域名下开放 `/.well-known/search` 接口，返回 Markdown 片段而非生成式答案；每个页面还会注入元标签告诉智能体这个接口的存在和调用方式，支持 GET 和新的 HTTP QUERY 方法。所有套餐可用（含免费版，有限额），按 AI Search 计价；对有文档站、博客的开发者来说，等于零搭建成本让智能体能搜自己的站。 [Cloudflare 官方博客](https://blog.cloudflare.com/search-for-agents/)

**论文与开源工具**

**6. llama.cpp 发布 v1.1.0：新增 Inkling 2、Hy4 flash 等模型家族与一批 TTS/音频模型，11月26日**
本地推理引擎时隔两周再发大版本：新增 Inkling 2 家族（base、Mini、DSpark）、220B MoE 的 Hy4 flash（每 token 激活 12B）、RAON-1-mini、Zaya1 8B、Domyn Edge 4B，以及 Kokoro、Zonos3-Mini、Kyutai Hibiki 等一批 TTS 与音频模型；新增 `--target-bpw` / `--target-size`，可按目标精度或目标文件大小自动做逐张量量化；llama-server 支持 OpenAI 风格的具名 tool_choice，聊天 Web UI 重做并支持语音消息和智能体轨迹；旧的 llama_batch API 标记为废弃，改用 llama_batch_ext。 [Your Computer（转述 GitHub 发布说明）](https://yourcomputer.com/news/2026-11-26-llama-cpp-v1-1-0/)

**7. 英伟达开源 Nemotron 3.5 Parse 的训练数据与微调配方：1888 万条合成样本，推理提速至 7.62 倍，11月26日**
针对 10 月发布的 0.631B 文档解析模型 Parse 3.5，英伟达在 Hugging Face 开源了三份训练用合成数据集：图表 998 万条、表格 100 万条、多语言 OCR 790 万条，合计约 1888 万条，均附图片、标注与生成文档；同时公开 SFT + RLVR（GRPO）两阶段微调配方和 DFlash2 推测解码器，单并发下吞吐从 0.54 页/秒升至 4.10 页/秒（官方称 7.62 倍）。适合想自己训一个专用文档解析模型、或把 Parse 适配到特定单据、语言的开发者；数据集均为合成数据，真实嘈杂扫描件上的效果需自行验证。 [Hugging Face 官方博客（NVIDIA 撰文）](https://huggingface.co/blog/nvidia/building-on-nemotron-35-parse-open-data-fine-tunin)
