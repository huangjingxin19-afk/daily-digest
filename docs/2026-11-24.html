新模型

1. 智谱发布 GLM-5.4：首个 Loop Transformer 旗舰，28 层循环两遍，11月23日

750B 规模的 GLM-5 基座上，28 层共享权重循环执行两遍，不增加参数换取更深推理；新增视觉能力，支持 100 万 token 上下文，可用代码做视频、工程 CAD、游戏与交互式 3D。Coding Plan 全量订阅用户即刻可用（ZCode 中为默认模型，Z.ai Chat 免费与付费用户均可），周额度高于 GLM-5.3，Coding Plan 文档显示积分系数约降三分之一。要注意：官方博客没有给出 750B 模型本身的跑分，只有 30B 同规模消融实验（平均分 70.3→73.2，GPQA-Diamond +4.0、SWE-bench Verified +4.1，但 SimpleQA 与 BrowseComp 略降），“可比 2T–3T 参数模型”只是官方说法；API 与开源权重都还在等安全评估，暂无日期。 Z.ai 官方博客 / 掘金（引述 Coding Plan 文档）

2. 蚂蚁发布 Ling-3.2-air：124B 原生多模态 MoE，MIT 协议开源，11月23日

总参数 124B、每 token 激活 5.5B，沿用 Ling-3.0-flash-VL 的原生多模态架构，256K 上下文，权重已上 Hugging Face，SGLang 首日即支持；Artificial Analysis 智能指数 23 分。做工作流自动化、专业文档推理这类任务时可以直接拿来部署，MIT 协议也允许商用。 Hugging Face 官方模型页

3. X Square Robot 发布具身基础模型 WALL-OSS-1.0，11月23日

原生视觉-语言-动作（VLA）预训练模型，以 Qwen3.5 为基座，把语言、视觉与机器人动作数据联合训练；312 项由评测者自由选择的开放式真机任务中，零样本成功率 55.1%。另有 4B 的 Lite 版与 2B 的 Nano 版面向轻量部署，XR Harness 开发者预览与 WALL-API-1.0 同步推出；但代码与权重尚未放出，官方称即将开源。 X Square Robot 官方博客

新应用与新功能

4. Anthropic 推出 Claude Ship：PR 评审、修复、批准交给三个智能体，11月23日

Code Review（已正式可用）审 PR 并核验发现，新增的 PR Steward（测试版）处理失败的 CI 检查、合并冲突与评审意见，Claude Approvals（测试版）按团队写在仓库里的策略文件自动批准常规改动、高风险的交还人工。面向 GitHub 仓库的 Claude Team 与 Enterprise 计划，Claude Code 里用 /ship 命令触发，按 token 计费。 Reuters

5. Google 搜索 AI Mode 接入 Wallet：花销与卡片信息进搜索上下文，11月23日

Personal Intelligence 今日起可接入 Google Wallet（需手动开启，仅读消费与卡片信息，不能动钱），可据此给省钱建议、信用卡权益用法；Drive 与 Gemini App 的接入在未来几周内跟进，AI Overviews 与 AI Mode 也开始按近期搜索上下文给出更个性化的回答。 Google 官方博客

论文与开源工具

6. DeepMind 用 Gemini 4 智能体小队优化量子线路，每项改进都经 Lean 证明，11月23日

多个 Gemini 4 智能体小组各自寻找更省资源的量子线路，成果先经 Lean 形式化验证才进入共享笔记：惯性约束聚变模拟成本降 11.8 倍，所需纠错量子比特从 5,650 降到 4,338；arcsin 例程快 290 倍，光敏分子模拟便宜 8 倍，细胞色素 P450 相关计算改善 2.5 倍。Lean 量子算法库、问题规范与已验证解法已在 GitHub 开源，论文见 arXiv:2611.09822。 Google DeepMind 官方博客
