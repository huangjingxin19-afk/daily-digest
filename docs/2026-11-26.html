AI 热点

AI 热点 · 11月26日

新模型

1. Cognition 发布 SWE-2.1：纯强化学习训出的编程模型，Terminal-Bench 分数翻倍，11月24日

在 Kimi K3 基础上继续纯 RL 训练，Terminal-Bench 4.1 自报从 24.2 升至 50.0，FrontierCode 2.0 从 24.1 升至 41.3；另有 Cerebras 加速的 Lightning 版（自报 600 token/秒）和放宽限制的 Cyber 安全版。只在 Devin Desktop/Cloud/CLI 内可用，无 API、无权重；全部跑分均为官方自报，尚无独立验证。 Unite.AI（转述 Cognition 官方发布）

2. JetBrains 开源 Mellum2.1 Instruct：12B MoE 编程模型，专做快问快答，11月25日

与 10 月的 Thinking 版同架构（12B 总参数、每 token 激活 2.5B），但跳过思维链直接给答案；SWE-bench Verified 自报 40.4%，是上一代 Instruct（20.2%）的两倍；智能体任务平均用 token 从 10,100 降到 5,600，少约 45%。Apache 2.0 协议，Hugging Face 上有 GGUF 版可本地跑，适合当子智能体做小修小补、省 token；难题能力明显弱于 Thinking 版。 JetBrains 官方博客

3. Midjourney 上线动漫模型 Niji V8：专用编辑模型接回角色一致性，11月24日

与 Spellbrush 合作的动漫分支，新增专用编辑模型：上传角色图加文字指令，就能把同一角色放进新场景、新姿势，补上 Niji 7 取消角色参考（cref）后的缺口；提示词依从性与画面连贯性也有提升。已向付费订阅用户开放，Discord 加 --niji 8 或网页端切换；官方未公布任何跑分与速度数据。 ASCII.jp

4. 商汤开源 SenseNova U1.6：8B 统一视觉模型会自己检查并修正图片文字，11月24日

同一权重兼顾理解、生成与编辑，新增原生自纠：生成信息图后对照提示词自查文字错误再重画一版；官方自报 UltraTextBench 密集信息图测试从 86.04 升至 92.28（相对提升约 7%）。Apache 2.0 协议，权重已上 Hugging Face，另有 4 步/8 步蒸馏 LoRA 与 GGUF 版；自纠训练主要针对信息图，其他题材效果待验证。 Hugging Face 官方模型页

5. 蚂蚁 inclusionAI 开源 Ling-3.2-air：124B 多模态 MoE，每 token 只激活 5.5B，11月23日

原生多模态混合线性 MoE，MIT 协议，权重已上 Hugging Face；官方自报工作流自动化评测 AutomationBench-AA 从 15.7% 升至 61%，并提供首日 SGLang/vLLM 部署支持。124B 参数、每 token 只激活 5.5B，4 张 141GB 显卡可跑 256K 上下文，适合自建部署做文档与流程自动化；跑分均为官方自报。 Hugging Face 官方模型页

新应用与新功能

6. Claude 的 artifact 可以装成桌面 App 了：Mac/Windows 独立窗口运行，11月24日

Anthropic 推出“Install as app”测试版，所有套餐（含免费版）可用：把 Claude 生成的计时器、看板、小工具等 artifact 一键装成独立 App，有自己的图标和窗口，改 artifact 后 App 自动同步。分三档权限，最高档“完全访问本机”可运行程序、读写删除文件，且 Anthropic 事先不审核这些 App；需 Claude 桌面端 6.28899.0 及以上，仍需联网登录。 MacRumors（转述 Anthropic 公告）

开放与套餐变化

7. MCP 两周年：Tasks 与 Elicitation 转正式，Skills over MCP 进公开测试，11月24日

Anthropic 在 MCP 发布两周年之际升级协议：后台长任务（Tasks）与中途向用户追问（Elicitation）正式可用，服务器可附带分步操作手册的 Skills over MCP 进入公开测试，文件上传即将推出；Pro/Max/Ultra 用户默认可用，Team 需管理员开启，企业版随后。官方称 MCP SDK 月下载量已超 7 亿次（7 月时为 4 亿次）。 The Decoder（转述 Anthropic 公告）

论文与开源工具

8. PrismML 开源 Ternary Bonsai 2.5 27B：27B 模型三值量化后只占 5.9GB，11月24日

基于 Qwen3.8-27B，权重全部压成 -1/0/+1（三值量化），体积从 53.8GB 压到 5.93GB，262K 上下文保留；官方自报智能体评测均分从 37.9 升至 54.2（提升约 43%），达到全精度父模型的九成。Apache 2.0 协议，Hugging Face 上有 GGUF 与 Apple Silicon 的 MLX 版，单机本地跑 27B 级编程智能体门槛再降一级；跑分均为官方自报。 Koda
