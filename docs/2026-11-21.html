新模型

1. 腾讯 Hy4 正式权重开源，11月20日

770B 参数 MoE 模型（每 token 激活 49B），支持视觉与电脑操作，上下文 100 万 token；同时放出 FP8 版和预训练 base 版，附系统卡与安全评估。需要注意：正式版改用自定义 Tencent Hy License，不再是预览版的 Apache 2.0，大规模商用需另行授权。 Hugging Face

2. Thinking Machines 发布 Inkling 2 Mini，11月20日

26.4B 参数的循环 MoE 模型，中间 12 层每 token 重复跑 3 次，每 token 仅激活 3.4B 参数；Apache 2.0 协议，权重约 20GB，可在笔记本本地运行，支持 100 万 token 上下文与图文输入。官方称其在 DeepSWE 等编码评测上领先同级开源模型。 来源

新应用与新功能

3. Perplexity 推出 Orchestrator API，11月20日

一个端点接入 OpenAI、Anthropic、Google、xAI 及开源模型，统一计费；同一模型出故障时自动切换到另一家部署商继续服务，不额外收平台费；另有预览功能 Routes，可用自然语言描述任务自动选模型。 Perplexity 文档
