1. 百度开源 ERNIE 5.5 Flash Preview 权重：280B 参数、每 token 只激活 14B，11月24日

权重已上 Hugging Face 与 ModelScope，Apache 2.0 协议，分三个版本（FP8+MXFP4 专家、纯 FP8、BF16），上下文 100 万 token，支持 vLLM/SGLang；但这只是中间检查点，百度明确说后训练还没做完、部分能力可能不完整，跑分也都是官方自报。想本地部署大参数稀疏 MoE、又不想被托管 API 绑住的可以直接拿来试。 AIbase 新闻

2. 蚂蚁开源医疗模型家族 LingSante：560B 推理模型 + 可跑笔记本的多模态模型，11月23日

两款主力权重已上 Hugging Face（MIT 协议）：LingSante-3.1-flash 总参数 560B、每 token 激活约 25B，100 万上下文，主打复杂医学推理与证据验证；LingSante-3.1-air-VL 124B/5.5B 原生多模态，能读影像、皮肤照片与体检报告。同系列还有预测未来六年 150 多种疾病风险的 LingSante-Pulse 等专用模型。医疗 AI 第一次有这种量级的开源权重可供复现与二次开发，但官方也明确这只是研究工具，不能替代临床诊断。 TechNode

3. KRAFTON 发布 Raon-1-mini 正式版：28.8B MoE，韩语与智能体任务见长，11月24日

总参数 28.8B、每 token 激活 4.3B，Apache 2.0 协议，已上 Hugging Face，支持 Transformers/vLLM/llama.cpp/MLX；官方自报 AIME 2026 96.7、GPQA Diamond 86.0，NVFP4 量化版单张 RTX 5090（32GB）可跑。30B 级开源模型里又多了一个韩语强、部署门槛低的选择，但跑分均为官方自报，尚无独立验证。 Hugging Face 官方模型页

6. OpenAI 预印本：GPT-6 不靠专用生物模型也能设计蛋白质，湿实验验证了结合，11月24日

GPT-6.2 仅凭推理与代码设计迷你结合蛋白，在与 Onava 合作的湿实验里，322 个候选中有 35 个（10.9%）结合了 PD-L1、IL-7Rα、TrkA、VEGF-A、IL-17A 五个靶点中的目标；抗体改造也有约七成保留结合。通用模型有望靠改提示词就切换蛋白设计任务，而不必为每个任务重训专用模型；但预印本未经同行评审，候选筛选仍靠 Boltz-2 等专用模型，且完整结构预测远弱于专用模型（TM-score 0.38 对 0.93）。 AI Weekly（转述 OpenAI 研究文章）
